Drop music here, then run Matcha > Build Scene.

File names decide where a track plays:
  Title...    title screen            e.g. "Title.ogg"
  Shop...     while the shop is open  e.g. "Shop 1 - Morning.ogg", "Shop 2 - Rush.ogg"
  Summary...  end-of-day summary      e.g. "Summary.ogg"

One track loops; several Shop tracks play one after another in name order.
Any format Unity reads works (.ogg, .mp3, .wav). Tracks import as streamed Vorbis.
